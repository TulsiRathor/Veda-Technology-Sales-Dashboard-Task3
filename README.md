# Veda Technology – Day 3 Sales Dashboard

## Project Overview
This project presents an interactive Sales Performance Dashboard created using Power BI and the Sample Superstore dataset.

The dashboard helps analyze sales, profit, quantity sold, category-wise performance, regional sales, and monthly sales trends.

## Tools Used
- Power BI
- Sample Superstore Dataset

## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Quantity Sold

## Visualizations
1. Sales by Category
2. Sales by Region
3. Monthly Sales Trend

## Interactive Feature
- Region Slicer: Filters dashboard data based on the selected region.

## Project Files
- `Veda_Day3_Sales_Dashboard.pbix` – Power BI dashboard file.
- `Dashboard_Explanation_Note.docx` – Dashboard explanation document.

## Conclusion
This dashboard provides a clear visual overview of business sales performance and helps users compare sales across different categories and regions.
